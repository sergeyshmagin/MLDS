# Sprint 15. Поведенческий скоринг банка «Ва-банк»

Модель предсказывает, возникнет ли у действующего клиента просрочка от 90 дней в ближайшие
12 месяцев. Объект наблюдения - пара «клиент - месяц скоринга».

## Состав

```
SPRINT_15/
├── 4376870f-e008-4a24-86eb-db222172727c.ipynb   тетрадь проекта
├── requirements.txt                              версии окружения платформы
└── artifacts/
    ├── behavioral_scoring_model.joblib           откалиброванная модель целиком
    └── model_meta.json                           порог, гиперпараметры, метрики, версии
```

Исходные датасеты (`ds_15_*.csv`) в репозиторий не выкладываются: они относятся к учебной
платформе и лежат в `/datasets/`.

## Итоговая модель

`Pipeline(OneHotEncoder + StandardScaler) → RandomForestClassifier` с балансировкой
`RandomOverSampler`, поверх - изотоническая калибровка вероятностей на отдельной выборке.

Правило решения: клиент **одобряется**, если калиброванная вероятность дефолта **ниже порога**
из `model_meta.json`.

## Инференс

```python
import json
import joblib
import pandas as pd

модель = joblib.load('artifacts/behavioral_scoring_model.joblib')
мета = json.load(open('artifacts/model_meta.json', encoding='utf-8'))

признаки = мета['признаки_категориальные'] + мета['признаки_числовые']
вероятность = модель.predict_proba(данные[признаки])[:, 1]
одобрен = вероятность < мета['порог_решения']
```

На вход подаётся сырой `DataFrame` с колонками из `model_meta.json` - препроцессинг зашит внутрь
модели. Признаки должны быть построены только по данным, доступным **до** даты скоринга; логика
сборки - в разделе «Объединение таблиц» тетради.
